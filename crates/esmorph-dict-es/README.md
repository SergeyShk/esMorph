# esmorph-dict-es

Spanish dictionary for the morphological analyzer [esMorph](https://github.com/SergeyShk/esMorph) in its binary format. The crate is used by `esmorph` through the feature `bundled` (on by default): `esmorph::Dictionary::bundled()`.
